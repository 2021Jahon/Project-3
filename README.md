# ⚽ Project-3 — Flashscore Parser & Resolver

Набор инструментов на Python для сбора футбольных данных с сайта Flashscore.
Позволяет выгружать результаты матчей, счёт первого тайма, продвинутую статистику (xG, xA, удары, владение) и красиво форматировать данные в Excel.

---

## 🚀 Возможности

Проект состоит из двух независимых скриптов:

### 1. Основной парсер (`flashscore_playwright.py`)
Собирает статистику по всем матчам выбранного турнира.
*   **Сбор сезонов:** Поддержка текущего сезона и архива (начиная с 2011 года).
*   **Продвинутая статистика:** 50+ метрик, включая `xG` (ожидаемые голы), `xGOT`, `xA`, удары, владение, дуэли, отборы и карточки.
*   **Умный парсинг:** Автоматически переводит русские метки Flashscore в стандартные английские ключи.
*   **Формат вывода:** Сохраняет данные в `CSV` и генерирует `JSON`-словарь со всеми названиями колонок.
*   **Защита:** Встроенные задержки и семафоры для избежания бана по IP.

### 2. Резолвер матчей (`resolve_match_ids.py`)
Находит финальный и промежуточный счёт по списку ID матчей.
*   **Входные данные:** Excel-файл с колонкой `match_id`.
*   **Точность:** Финальный счёт (FT) берется напрямую из HTML (как видит пользователь), а счёт первого тайма (HT) — из API.
*   **Очистка данных:** Автоматически убирает мусор из названий лиг (например, « - Тур 5»).
*   **Форматирование:** Записывает результат в `matches_scores.xlsx` с настроенной шириной колонок, жирной шапкой и заморозкой первой строки.

## 🛠 Установка

### Требования
*   Python 3.14 или выше
*   Установленный браузер Chromium (скачается автоматически)

### Шаги

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/Jahon/Project-3.git
   cd Project-3

2. Создайте и активируйте виртуальное окружение:
# Windows
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1

# Linux / macOS
   python3 -m venv .venv
   source .venv/bin/activate

3. Установите зависимости:
   pip install -r requirements.txt

4. Установите браузер для Playwright:
   playwright install chromium
